# VERIFIED — Official court filings (renamed)

Every official court record in this repository that could be identified as a pleading, motion, exhibit packet, summons, order, judgment, mandate, or other document entered with a court.

## Filename format

`yyyy-mm-dd_DOCUMENT-TITLE_CASENUMBER_COURT.pdf`

Example from the May 2017 Crowder packet:

`2017-05-01_PETITION-FOR-CITATION-OF-CONTEMPT_CV-2016-422W_LAFAYETTEMS-CHANCERY-COURT.pdf`

- **Date** — clerk file-stamp date when visible on page 1 (or the signature page). If the stamp is unreadable, the date from the original filename is used.
- **Title** — document caption, uppercase hyphenated.
- **Case number** — as printed on the first page (CV-2016-422W, L17-233, 2020-CP-01259-COA, 3-25-CV-00203, …).
- **Court** — normalized court id (LAFAYETTEMS-CHANCERY-COURT, MS-COURT-OF-APPEALS, TXSD-GALVESTON, …).

See `INDEX.md` for the full old-name → new-name map (212 official filings).

## What is included

Pleadings, motions, answers, counterclaims, summonses, proof of service, cover sheets, orders, judgments, writs, mandates, filed briefs, and file-stamped exhibit packets.

The May 2017 Crowder compilation is kept as one official packet and the standalone extracts already in the repo are also listed under caption titles.

## What is not included

News clippings, Facebook exports, emails, tax/business filings, press credentials, call transcripts, FOIA production dumps, and unpublished manuscripts.
